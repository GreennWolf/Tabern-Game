## Estrategias de Identificación

### Documentos de Gremio/Orden

**FÁCIL de verificar:**
- Guerrero (sello militar)
- Paladín (orden sagrada)
- Clérigo (templo)
- Mago (círculo arcano)
- Bardo (licencia artista)

**DIFÍCIL:**
- Pícaro (NO tienen legales, son falsos)
- Hechicero (magia innata, sin organización)
- Bárbaro (tribus no usan burocracia)
- Druida (círculos no usan documentos)

### Apariencia Visual

**OBVIO:**
- Guerrero (armadura, armas)
- Paladín (símbolos sagrados brillantes)
- Mago (túnica, báculo, tinta en dedos)
- Bárbaro (pieles, salvaje)

**SUTIL:**
- Pícaro (se ven "normales" - ESE ES EL PUNTO)
- Monje (simple, túnica)
- Hechicero (marcas sutiles)

### Comportamiento

**DISTINTIVO:**
- Paladín (juzga todo)
- Bárbaro (agresivo, impaciente)
- Bardo (dramático, canta)
- Pícaro (toca cosas, observa salidas)

**NORMAL:**
- Plebeyo (sin señales)
- Guerrero (disciplinado pero normal)

## Notas de Balanceo

- **Early:** 95% clientes seguros (tutorial)
- **Mid:** 60% seguros (desafío moderado)
- **Late:** 40% seguros (máximo desafío)

- **Plebeyos:** Siempre presentes (20% late) para dar "descanso"
- **Clases raras:** Eventos especiales garantizados
- **Eventos escalados:** No todos los días son caos

**Curva de aprendizaje:**
1. Días 1-5: Solo plebeyos + guerreros (mecánica básica)
2. Días 6-10: + Primeros pícaros (detección de mentiras)
3. Días 11-15: + Magia (nuevos peligros)
4. Días 16-20: + Clases expertas (complejidad)
5. Días 21+: Todo posible (maestría)
