# 🥋 MONJE

## Descripción

Maestro de disciplina interior, artes marciales y meditación. Rechaza excesos, busca perfección del ser. Tranquilo pero letal.

**Rol:** Monasterio, ermitaño, guardaespaldas, maestro

| Nivel | Efecto |

**Resistencia:** NINGUNA (generalmente no portan armas)
**Excepción:** Bastón ceremonial (no cuenta como arma)

**Diálogo:**
- "No porto armas. Mis manos bastan."
