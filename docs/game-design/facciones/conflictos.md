# ⚔️ Conflictos y Relaciones entre Facciones

Este documento define las relaciones entre todas las facciones, incluyendo alianzas, rivalidades y enemistades.

---

## 🎯 SISTEMA DE RELACIONES

### Niveles de Relación

**Entre facciones:**

```
+5:  ★★★★★ ALIADOS CERCANOS - Cooperación activa
+3:  ★★★★  ALIADOS - Relación positiva, ayuda mutua
+1:  ★★★   AMISTOSOS - Cordiales, sin conflicto
 0:  ★★    NEUTRALES - Sin relación significativa
-1:  ★     TENSIÓN - Desconfianza, fricciones menores
-3:         RIVALES - Competencia, conflictos frecuentes
-5:         ENEMIGOS MORTALES - Guerra abierta
```

### Impacto en el Jugador

**Si tienes alta reputación con Facción A (+50) y:**

**Facción B es ALIADA de A (+3 o +5):**
- Ganar reputación con A → +10% reputación con B automáticamente
- Ejemplo: +20 con Guardia Real → +2 con Templo de la Luz

**Facción C es RIVAL de A (-3):**
- Ganar reputación con A → -20% reputación con C
- Ejemplo: +20 con Guardia Real → -4 con Gremio de Ladrones

**Facción D es ENEMIGA MORTAL de A (-5):**
- Ganar reputación con A → -50% reputación con D
- Ejemplo: +20 con Guardia Real → -10 con Gremio de Ladrones (si fueran enemigos mortales)

## 🎯 EVENTOS DE CONFLICTO

### Guerra de Facciones

**Cuando dos facciones enemigas (-5) entran en conflicto abierto:**

**Ejemplo: Guardia Real vs Gremio de Ladrones**

```
DÍA 45: EVENTO MAYOR
"OPERACIÓN LIMPIEZA"

La Guardia Real lanza operativo masivo contra el Gremio de Ladrones.

Tu posición:
- Guardia Real: +35 (Amistoso)
- Gremio de Ladrones: +25 (Amistoso)

DEBES ELEGIR:

Opción A: Apoyar a Guardia
- Reportar pícaros que veas
- Permitir que guardias usen tu taberna como base
- Resultado: Guardia +40, Gremio -80

Opción B: Apoyar a Gremio
- Esconder pícaros
- Mentir a guardias
- Resultado: Gremio +40, Guardia -80, RIESGO ARRESTO

Opción C: Neutralidad
- Cerrar taberna durante conflicto (3 días)
- Resultado: Guardia -10, Gremio -10, SIN GANANCIA

Duración: 7 días
```

**Frecuencia:** 1 guerra mayor cada 30-60 días (aleatorio)

### Alianzas Dinámicas

**Las relaciones pueden cambiar según eventos del mundo:**

**Ejemplo:**
```
DÍA 60: "AMENAZA COMÚN"

El Culto de Sangre ataca la ciudad.

Efecto temporal:
- Guardia Real + Templo Luz + Orden Escudo + Círculo Arcano
  forman alianza temporal

Si apoyas la defensa:
- +20 con TODAS las facciones buenas
- -60 con Culto de Sangre
```

## 💡 DISEÑO DE CONFLICTOS

### Principios

1. **No todos son enemigos mortales:**
   - Solo conflictos irreconciliables son -5
   - Mayoría son -3 (rivales) o -1 (tensión)

2. **Triángulos de poder:**
   - Legal: Guardia, Templo, Orden
   - Criminal: Gremio Ladrones, Sombríos
   - Neutral: Comerciantes, Círculo Arcano
   - Natural: Hermandad, Consejo Élfico

3. **Aliarse con uno afecta a otros:**
   - Imposible estar bien con todos
   - Fuerza decisiones estratégicas

4. **Recuperación posible:**
   - Incluso -5 puede mejorarse (difícil)
   - Eventos especiales pueden reconciliar facciones

---

**Sistema de Conflictos:** Define las tensiones políticas del mundo y fuerza al jugador a tomar partido.
